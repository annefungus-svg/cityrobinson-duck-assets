## 拓竹打印方案

完整资产包的 **03_拓竹打印方案** 目录提供 7 个 .3mf 工程、通用 STL 和装配示意图。

| 方案 | 用途 |
| --- | --- |
| V27 X1C 白色 PLA 100mm | 原整件方案 |
| V27 P1S 白色 PLA 100mm | 原 P1S 整件方案 |
| X1C 整件后仰 35 度，单只 | 整件打印备选 |
| X1C 低支撑前后分件，单只 | 减少可见外观面的支撑接触 |
| X1C 低支撑前后分件，三只同板 | 三只分件同时打印 |
| X1C 免胶卡扣，单只 | 前后分件通过隐藏卡扣装配 |
| X1C 卡扣松紧试片 | 验证卡扣公差和装配手感 |

使用 **Bambu Studio → 打开工程** 打开 .3mf。主方案按 X1C、0.4mm 喷嘴、PLA、Cool Plate、约 100mm 高设置；P1S 文件另行标注。打印前按实际设备、耗材与打印板核对并重新切片。

低支撑方案仍存在少量局部悬垂，请查看切片预览和支撑提示。分件会留下装配接缝。免胶卡扣配合尚未实机验收，**先打印松紧试片**再确定公差。通用 STL 仅含几何，不包含打印参数。
